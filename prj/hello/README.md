# Projeto hello

Projeto criado com o script `gen-prj.sh`.

## Estrutura

- `rtl/`: implementação do DUT.
- `tb/`: testbench.
- `docs/`: documentação do projeto.

## Objetivo

Montar uma estrutura básica de projeto para práticas de Design Verification com SystemVerilog.

## Como foi criado

Na raiz do repositório:

```bash
./gen-prj.sh hello
```
