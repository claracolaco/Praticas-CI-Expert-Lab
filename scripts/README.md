# scripts

Esta pasta contém scripts shell usados nas práticas iniciais.

## Arquivos

### `hello.sh`
Script simples criado para testar:
- criação de arquivo script;
- permissão de execução com `chmod +x`;
- execução no terminal;
- uso de alias.

## Como rodar

Dentro da pasta `scripts/`:

```bash
chmod +x hello.sh
./hello.sh
```

## Saída esperada

```bash
say hello
```
